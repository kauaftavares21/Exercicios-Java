☕ Exercícios em Java – Estruturas Condicionais
Este repositório contém exercícios práticos desenvolvidos em Java, com foco no domínio das estruturas condicionais if, else if, else e switch. Os exercícios variam de problemas básicos a cenários mais realistas, visando fortalecer minha lógica de programação e boas práticas na linguagem.

🧠 Conteúdo Abordado
Verificação de números pares e ímpares

Comparação entre dois números

Identificação de dias úteis e finais de semana

Uso de entrada de dados com Scanner

Tratamento de strings com métodos personalizados (ex: capitalize)

Aplicações com switch para múltiplas condições

Boas práticas como fechamento de recursos e modularização de código

🎯 Objetivo
Este projeto tem como objetivo documentar minha evolução na linguagem Java, reforçar conceitos fundamentais de estruturas condicionais e servir como referência para estudos futuros e para outros iniciantes na linguagem.
